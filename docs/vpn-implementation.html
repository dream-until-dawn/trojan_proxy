Trojan适配器与受限执行器

总览计划

协议边界

首版只启用Trojan，使用独立端口和可信证书。业务层持有结构化配置，通过协议适配器生成固定版本sing-box配置；不向后台开放原始引擎JSON或任意启动命令。后续协议须声明TCP/UDP、证书和客户端导出能力，复用认证、修订与故障恢复。

秘密与进程隔离

VPN配置中的随机密码以独立AAD的AES-GCM密文保存在配置修订中，普通状态接口不返回密码。导出客户端配置必须近期MFA，并明确提示下载文件含凭据。管理令牌和VPN口令不得写入URL、日志或浏览器持久存储。

独立runner进程运行固定路径的sing-box，只通过权限0660的专用Unix socket接受check/apply/status。runner容器使用UID10002、受控共享GID10001，仅读取已发布证书，无Docker socket、认证数据库或主密钥。运行配置只存在专属tmpfs的0600文件中，控制服务在runner重启后恢复配置。

应用与回退

先执行引擎check，再替换运行进程；检测启动失败后恢复旧配置。每次应用返回配置指纹和实际进程状态，协调器只有在目标一致时提交。VPN变更可能短暂断开其现有连接，反代变更不触碰VPN；VPN故障不触发网关重启。证书轮换生成不可变新版本，VPN成功加载后才更新修订引用。

目的地址限制

VPN仅用于公网访问，拒绝回环、私网、链路本地、云元数据、组播和服务器自身地址。域名须先由指定解析器解析，再检查解析后的地址；不得因域名请求绕过IP检查或在检查后重新解析到不同地址。后台及宿主机本地业务通过管理规则访问，不由VPN直达。

分步验证

  1. 结构化输入、证书引用和配置生成正反向测试；固定引擎真实check。
  2. Mihomo真实TCP/UDP，错误密码/根证书，私有IP/域名解析到私网，DNS改变，目的地址保护定向破坏。
  3. 真实runner启动、错误配置/占用端口、回滚、进程退出与容器重启恢复；确认网关指纹不变。
  4. 新服务在独立端口并行运行，由所有者在Clash Verge与Clash Mi导入验证；通过后才接管旧80/443并验收公共ACME。
