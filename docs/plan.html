ID问题方法与成功标准失败处理
P1 网络host 网络是否满足 loopback 与动态端口？Linux 隔离高端口临时服务；Caddy 请求 127.0.0.1 上游；增加两个监听，验证只改网关配置，无需重建容器。明确 Linux 限制；验证专用 host relay 备选，不能默默依赖 Desktop 差异。
P2 配置应用坏配置与崩溃如何保住旧配置？好配置生效；非法 upstream/重复监听/端口占用失败；故意在 prepared/apply/commit 间中断，恢复到一致修订。先完成状态机和回滚设计，再扩展 UI。
P3 TLS 与交接80/443 所有模式是否兼容？高端口模拟保留 listener→TLS→失败回滚；再在授权窗口真实 80/443 验证 IPv4/IPv6。验证 ACME 路径不被跳转吞掉。修正 portguard/协调协议；不得改为不占 443 来假装通过。
P4 证书发布Caddy 证书如何可靠给 VPN 使用？本地短期证书轮换，匹配校验、原子发布、引擎激活、握手指纹、坏密钥回滚；固定存储适配版本。评估独立 ACME 服务统一签发；不能让两套组件争抢证书管理。
P5 协议候选引擎是否兼容实际客户端？Trojan 独立端口真实端到端，正确/错误认证、TLS 校验、TCP/UDP、重连、证书轮换；客户端名单待开发前补充。保留 Trojan 原引擎独立适配，避免因为替换引擎丢兼容性。
P6 公开目录路径边界是否挡住动态攻击？临时目录正向下载；../、双重编码、隐藏文件、符号链接、并发换链均不能读到根外哨兵文件。使用受限文件打开 API，必要时独立静态容器；不以静态 realpath 校验替代运行期保护。
P7 鉴权成本单机口令安全是否可用？目标主机 Argon2id 内存与耗时；并发失败登录受限；TOTP 时间漂移/重放、SSH 恢复；控制面不影响数据面。调整预算与并发限流；不降为快速散列。

所有探针：指定时间上限、独立容器名/目录/端口、记录镜像摘要与退出状态，清理仅限本次创建的资源；不得使用全局 prune。真实 CA/云安全组变更需具备明确目标域名或规则，不猜测。
