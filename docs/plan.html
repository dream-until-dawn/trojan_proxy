依赖顺序：M0 → M1 → M2 → M3 → M4 → M5 → M6 → M7。每阶段更新设计和验收证据，再推进下一阶段；现阶段不直接进入大规模实现。

必须先做的有界探针

ID问题方法与成功标准失败处理
P1 网络host 网络是否满足 loopback 与动态端口？Linux 隔离高端口临时服务；Caddy 请求 127.0.0.1 上游；增加两个监听，验证只改网关配置，无需重建容器。明确 Linux 限制；验证专用 host relay 备选，不能默默依赖 Desktop 差异。
P2 配置应用坏配置与崩溃如何保住旧配置？好配置生效；非法 upstream/重复监听/端口占用失败；故意在 prepared/apply/commit 间中断，恢复到一致修订。先完成状态机和回滚设计，再扩展 UI。
P3 TLS 与交接80/443 所有模式是否兼容？高端口模拟保留 listener→TLS→失败回滚；再在授权窗口真实 80/443 验证 IPv4/IPv6。验证 ACME 路径不被跳转吞掉。修正 portguard/协调协议；不得改为不占 443 来假装通过。
P4 证书发布Caddy 证书如何可靠给 VPN 使用？本地短期证书轮换，匹配校验、原子发布、引擎激活、握手指纹、坏密钥回滚；固定存储适配版本。评估独立 ACME 服务统一签发；不能让两套组件争抢证书管理。
P5 协议候选引擎是否兼容实际客户端？Trojan 独立端口真实端到端，正确/错误认证、TLS 校验、TCP/UDP、重连、证书轮换；客户端名单待开发前补充。保留 Trojan 原引擎独立适配，避免因为替换引擎丢兼容性。
P6 公开目录路径边界是否挡住动态攻击？临时目录正向下载；../、双重编码、隐藏文件、符号链接、并发换链均不能读到根外哨兵文件。使用受限文件打开 API，必要时独立静态容器；不以静态 realpath 校验替代运行期保护。
P7 鉴权成本单机口令安全是否可用？目标主机 Argon2id 内存与耗时；并发失败登录受限；TOTP 时间漂移/重放、SSH 恢复；控制面不影响数据面。调整预算与并发限流；不降为快速散列。

所有探针：指定时间上限、独立容器名/目录/端口、记录镜像摘要与退出状态，清理仅限本次创建的资源；不得使用全局 prune。真实 CA/云安全组变更需具备明确目标域名或规则，不猜测。

规则域名/路径、WS 和自定义端口重复规则、自循环、后台路径遮蔽、命令注入、元数据地址删除对应校验后，指定非法规则被接受导致测试失败

每个 mutation 必须证明测试因目标保护缺失而失败，并记录具体断言；不能只看退出码红了。测试固定版本、可复现夹具与明确预期，不用“任何非零都算成功”的脚本。

最终一键部署体验

  1. 从带校验清单的发布包运行 ./install.sh（拟定入口，不是当前可执行功能）。
  2. 选择无域名/域名，填写域名和通知邮箱（需要时）、公开目录映射；工具执行只读环境与端口预检。
  3. 生成秘密文件，启动固定镜像；本地完成管理员 TOTP 绑定，打印一次性恢复材料和后台访问方式。
  4. 域名模式等待证书并显示失败原因；无域名模式打印可复制的 SSH 隧道命令；首版无证书不启用 Trojan。
  5. 后台创建反代/目录规则、设置 Trojan 密码并导出客户端配置；显示生效结果及回滚入口。
  6. 提供 status / doctor / backup / restore / upgrade / rollback / stop，停止保留数据；删除数据是单独显式命令。

系统不要求用户手写 Nginx/Caddy 配置、进入容器装软件或手工维护 cron。域名解析、云端口放行、Docker 安装前提和证书失败会以中文给出明确修复步骤。

服务器测试与发布管理

用户已提供测试服务器密钥路径，并授权启停/删除本项目镜像 guagua8719/trojan 对应容器。操作前必须通过实际 inspect 确认容器身份、AutoRemove、挂载、网络与日志；先导出运行信息/日志，必要时一致性备份，再进入会中断服务的测试。此授权不扩展到其他业务容器或全局资源清理。

设计/实现使用 codex/ 分支；每阶段完成检查后提交。远端推送、合并和 tag 已获用户一般授权，但仅在内容成熟且对应验证完成时使用，不把草案 tag 为成品。生产部署手册应绑定确切提交和镜像摘要，保留回退版本。

全新部署不要求保留旧架构。若后续决定沿用旧域名/证书/口令，应转为明确迁移任务，核实旧值有效性并安排暴露凭据轮换。

每一阶段完成时报告：变更、证据、失败/限制、下一阶段入口。未执行的测试不得写成已通过。
