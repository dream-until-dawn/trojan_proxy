  2. 每个附加域名单独自动HTTP-01签发和续期，复用持久Caddy缓存与现有证书校验器；保留逐域就绪状态。单域DNS/证书失败不降级为明文业务，也不影响其他域。默认不使用泛域名证书，不要求DNS API密钥。

  4. 后台以独立Origin+根路径建立身份，近期MFA、会话、来源检查及候选到期撤回继续有效。旧入口与候选并存期间仅叠加候选后台及其证书，不提前切换公共业务或VPN。确认必须来自新Origin且证书有效。
  5. 网站访问按域名分别记录与筛选，7/30天策略不变；不与VPN统计合并。配置备份/恢复和离线回退需要识别新增域名及后台身份。
