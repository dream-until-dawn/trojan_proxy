可行性发现与修正

  1. 原裁剪网关没有注册filter编码器，真实启动明确拒绝，已引入Caddy原生日志模块；必须同步升级gateway和control，不能先把新配置交给旧网关。
  2. 独立临时网关确认请求/响应头、查询、正文及伪造XFF不在原始文件，502运行错误日志也已去除请求秘密。正式编译器实测80跳转、robots、443默认页、/proxy、HTTP自定义端口、HTTPS错误、404，共7条且原始路径未因StripPrefix改变。
  3. roll_interval仅在新写入时判定，不能单独保证完全空闲时清理。改为roll_minutes=[0]整点定时轮转，加上大小和间隔轮转。真实夹具仅把整点提前到下一分钟，无新请求时也确实产生备份文件；不是用第二次写入冒充空闲验证。
  4. 日志从共享caddy-data专用子目录只读采集，未扩大control挂载权限。目录0700、文件0600；真实连接IP取remote_ip，不读client_ip/XFF。原生日志无采样，故障或耗尽有限缓冲时明确报告可能缺口。
