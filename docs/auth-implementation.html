单管理员初始化与来源隔离

总览计划

初始化只在终端进行

proxyctl admin-init 在交互终端隐藏输入强口令，生成 TOTP 秘密和一次性恢复码，由操作者在手机验证器中绑定，并输入有效六位验证码后才保存账户。未初始化时公网登录接口关闭，不提供注册。工具不把秘密写入日志。

认证秘密用独立文件中的随机256位主密钥经AES-GCM加密后存入SQLite；恢复码只存SHA-256散列。使用恢复码登录后该码立即作废；恢复和TOTP消费计数均用持久化条件更新防止重放。服务器root仍处于信任边界内。

浏览器与会话

后台按已确认来源 https://qin-xin.top:8007 提供服务；同域名其他端口不能获得内存里的令牌。令牌不放Cookie/URL/浏览器持久化存储，刷新需要重新登录。API要求精确Origin，Authorization承载短期随机会话；空闲30分钟、最长12小时。重启控制服务撤销全部内存会话。

第一次可交付界面使用嵌入Go镜像的本地HTML、CSS与JavaScript模块；当前界面规模小，不引入前端构建链，后续复杂度增加再评估React。模块按认证、状态及业务功能分目录，保持与API解耦。所有静态资源同源、禁止内联脚本，采用严格CSP。

服务边界

control仅监听宿主机回环地址，由Caddy的8007 HTTPS入口代理。Host和Origin必须匹配配置；不信任客户端提供的转发头。登录使用单并发散列预算及失败退避。不存在用户选择或密码找回邮件；初始化、恢复材料领取需要服务所有者在终端完成。

测试覆盖未认证API拒绝、错误口令与验证码、消费计数重放、恢复码单次使用、跨端口Origin拒绝、会话过期/退出、服务器重启撤销；前端不显示原始服务器错误堆栈。
