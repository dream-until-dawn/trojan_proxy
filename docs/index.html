D1无域名 HTTP 与强制跳转的关系无域名：80 提供 HTTP、443 保留拒绝业务；有域名且证书就绪：80 跳转 443，ACME 验证除外。无域名后台仅走本机/SSH 隧道。已确认
D2VPN 协议、客户端及 443先兼容 Trojan，使用独立端口；适配器预留其他协议。服务器 8443 已被占用，不能直接使用该示例值；具体端口在初始化时检查并确定。已确认电脑Clash Verge、手机/平板Clash Mi；新并行端口18443部署前已实测空闲。协议及独立端口已确认
D3部署平台及现有服务全新部署；用户授权在其服务器测试，并可启停/删除本项目容器。已核实 Alibaba Cloud Linux 3.2104 U10、x86_64、Docker 26.1.3、Compose 2.27.0。已确认并核实
D4独用后台鉴权单管理员，强口令 + 手机验证器 TOTP；无注册/多用户/找回邮件。保留离线恢复码，公网后台必须 HTTPS；新增计划将终端初始化改为 SSH 隧道内的网页向导。已确认
D5无域名是否也必须立即有 VPN允许首版无域名只启用 HTTP 反代；Trojan 等域名证书或导入可信证书后启用。首版不强行增加第二协议。已确认
D6额外端口及目录8001/8002 示例按 HTTP 默认；可为带域名的端口显式启用 HTTPS。目录发布只读、默认关闭索引；开启后允许列目录与下载，不支持上传/执行。建议默认
D7域名与证书范围首版普通域名/子域名、HTTP-01 自动签发续期与手工导入；泛域名和 DNS-01 作为后续扩展。用户已确定后台使用 qin-xin.top，按 8008 起递减选端口；实测选定 8007。不同端口不隔离 Cookie，改用页面内存令牌并严格校验来源。建议默认
