用户手册首次部署版本说明

部署包与源码包

首次部署下载trojan-proxy-v1.0.0.zip及同名.sha256即可，包含固定摘要清单和可离线浏览的HTML手册。开发、审计或自行构建时下载trojan-proxy-v1.0.0-source.zip及其校验文件；源码包包含完整仓库、构建脚本和三个Go模块各自的vendor依赖源码与许可证文件。不要把源码包根目录的旧版docker-compose.yml当作当前部署入口。

每个附件绑定同一个正式标签。release-manifest.json记录发行提交、镜像源码提交、镜像摘要、源码附件SHA256及离线依赖闭包检查结果。本版镜像来源为3edd775d0e1d2ddf9235bdecbac675cfa8435476；收尾只修改用户资料和发行流程，工具会检查运行源码等价。

离线核对源码依赖

使用与发行相同的Go1.26.11工具链，在源码包对应目录分别执行下列命令；三个模块各有独立vendor，不能只检查根模块。下例在Linux命令行执行：

GOPROXY=off GOSUMDB=off go list -mod=vendor -deps ./...
cd engines/trojan
GOPROXY=off GOSUMDB=off go list -mod=vendor -deps ./...
cd ../gateway
GOPROXY=off GOSUMDB=off go list -mod=vendor -deps ./...

发行流程已对Linux/amd64、CGO关闭的三个模块执行离线依赖图检查；不是承诺任意工具链或架构均可构建。Dockerfile构建仍需先取得所锁定的构建/基础镜像；直接在相应模块用go build -mod=vendor可使用附带依赖。
