按现象排查

现象检查步骤
prepare失败/80或443被占先看prepare日志和ss监听；本项目不会停止原网关。即使无域名也必须释放这两个端口。
无法打开18092在本机电脑建立SSH隧道，浏览器访问127.0.0.1而非服务器IP。首次绑定完成后18092关闭属于正常。不要将初始化端口开放公网。
setup-token拒绝输出使用交互SSH和docker compose exec；不要加-T、重定向或管道。绑定完成后不能再次发首次令牌。
候选确认提示入口/证书/期限不符刷新状态，超过5分钟需重新生成；从页面提供的新入口登录，在证书就绪后确认，不要一直使用旧入口或已过期页面。
验证码错误/登录失败核对服务器与手机时间、使用下一组验证码，等待限流结束；候选超时可能已恢复旧入口。不要发送验证码给他人。
证书申请一直未就绪核对A/AAAA均真实指向可达地址，公网80/443开放，域名填法和DNS生效，邮箱及系统时间正确。CA限流时不要无限重试。
域名HTTPS正常但VPN超时确认节点端口和SNI正确、客户端订阅已更新并选中、系统代理/TUN已启用；独立18443需放行，最终仅回环模式则必须使用共享443。
反代502先从宿主机访问相同上游IP:端口；服务尚未启动、重建或拒绝连接会真实返回502。不要用刷新成功覆盖故障记录。
反代丢样式或跳到其他应用检查路径剥离与应用basePath，网关不会重写资源/重定向/Cookie；优先使用独立子域名。
目录403/404核对显式挂载、文件权限、绑定ID与相对路径；未开启浏览列表时不能期待目录列出。
订阅链接失效核对有效期、设备授权是否撤销、管理员是否重置/恢复、当前是否HTTPS且VPN可用。丢失原URL时重建，不向第三方转换站提供。
访问统计看不到真实IP来源按真实连接计算，中间CDN/代理会改变连接方；白名单只分类，不控制访问。不应盲信任意X-Forwarded-For。
磁盘增长或采集异常查看磁盘、采集状态、容量边界与保留期。不要直接删除正在使用的数据库、WAL、证书或Docker卷。
不小心启动成全新后台先核对Compose目录、项目名及命名卷是否与原部署一致，停止错误的新实例并恢复原清单；不要反复初始化覆盖已有状态。

提交公开Issue前

提供发行版本、CPU架构、Docker/Compose版本、发生时间、脱敏错误和最小复现步骤。不要提供管理员口令、TOTP、恢复码、私钥、订阅URL、数据库、完整备份、Cookie或请求正文。可以提供HTTP状态、哪个端口/域名类别和已做过的对照测试。

三个核心容器健康不代表所有上游应用永不重建。核心24小时验收与整站可用性应分别说明：本版核心范围经过所有者验收，原整站两次外部上游502记录仍保留，不宣传整站零失败。
