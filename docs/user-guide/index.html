你会得到什么

一个入口

80/443统一管理。无域名先用HTTP，有域名自动申请证书、开启HTTPS并将HTTP跳转到HTTPS。

独用后台

强口令＋手机验证器。按域名、路径和端口管理反代、只读目录、证书和VPN。

VPN与订阅

Trojan与网站共享443，普通网页访问回落到网站；Clash Verge / Clash Mi可用URL导入和更新。

最短上手路线

  1. Linux/amd64服务器安装Docker Engine与Compose插件，保证80、443空闲。
  2. 下载v1.0.0发行ZIP并核对SHA256，在deploy目录运行一条Compose启动命令。
  3. 通过SSH隧道绑定管理员、手机验证器和恢复码。
  4. 需要HTTPS时配置DNS，在后台填写域名、自动证书和后台子域名，确认新入口。
  5. 添加反代；需要VPN时启用Trojan，创建每台设备的订阅。

部署前须知

本版正式支持Linux/amd64，建议至少2GiB内存，并为系统、其他应用和统计数据保留余量。三个常驻容器的内存上限合计512MiB，prepare为一次性服务；宿主机和Docker额外占用不包含其中。首次拉取需要访问ghcr.io；不用在服务器安装Go、Node或数据库。

一个服务器只部署一套本项目。它将独占80/443，不会自动停止已有Nginx/Caddy或修改云防火墙。域名和公网可达条件由你提供，后台不会自动操作DNS。公开目录内的文件可匿名读取。
