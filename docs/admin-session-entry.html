补充设计

双入口期间，仅检查请求Host/Origin并不等于检查令牌的来源。旧入口令牌若被复制，客户端仍能发送带新Host/Origin的请求。为落实“新入口重新登录确认”，每次登录的内存会话绑定服务器选中的入口身份（Origin和管理路径），所有受保护接口均检查该身份，包括被动轮询。伪造请求头不能改变已有令牌的绑定，也不能借错误入口延长其空闲期限。

新入口需要独立完成双因素登录；旧入口令牌不能读新后台、修改设置或确认候选。新入口令牌也不能回旧入口。退役入口令牌不自动迁移。无需修改数据库格式，账号、TOTP消费及恢复码不变；升级使内存会话失效，仍需所有者重新登录。

验收与上线门槛

先用真实认证服务和SQLite建立双入口回归，验证旧令牌加新Origin/Host必须401；覆盖同域不同管理路径、独立域名、各自合法会话、退役入口与被动轮询空闲期限。删除入口比较的定向破坏必须导致这条指定断言失败。该增量改变control程序，必须重新执行完整36项候选CI、固定镜像并匿名完整拉取；不得继续将0a1a73a的旧镜像结论用作本增量证据。原生产观察器和服务继续保持，直到原24小时终审及新候选均通过。
