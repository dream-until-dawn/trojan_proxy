本版交付

已知边界

  • 仅提供Linux/amd64正式镜像；Windows/macOS Docker Desktop与ARM不是本版部署承诺。
  • 单管理员；只有Trojan已实现，其他VPN协议为接口扩展点，不是已上线功能。
  • 反代上游只允许宿主机回环IP；远程IP、上游HTTPS、任意容器名不属于本版配置能力。
  • 无域名时443保留而不提供HTTPS；有可信证书后80跳转443。后台必须经隧道或可信HTTPS访问。
  • 目录发布仅限显式只读挂载；robots/noindex是声明，不是访问控制。
  • 订阅撤销阻止后续拉取，不使已下载的Trojan口令失效；需要撤销节点访问时应轮换VPN口令。
