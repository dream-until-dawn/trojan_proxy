总览架构计划

当前启动链路

Dockerfile.trojan：Alpine latest + Bash/Nginx 等工具
  → scripts/install.environment.sh
  → 启动时安装 acme.sh 与 Trojan（在线最新版 / 本地归档回退）
  → Nginx 监听 80，提供 config/dist 中的静态页面
  → Trojan 监听 443，TLS 终止；非 Trojan 流量回退至 127.0.0.1:80
  → 缺少证书时尝试 ACME → 重启 Nginx/Trojan
  → tail -f /dev/null 保持容器存活

管理入口是容器内交互式菜单；没有 Web 后台、账号/会话、路由持久化模型、配置事务、证书状态页和协议适配层。前端目录为构建产物，仓库没有对应源码和构建依赖清单。

另有 scripts/trojan_mult.sh：旧版宿主机安装脚本，未被 Docker CMD 调用。它与容器路径分开审计，不能把旧脚本的能力当作当前容器能力。
